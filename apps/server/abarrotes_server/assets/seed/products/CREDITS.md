# Fotos de los productos de ejemplo

(`lib/src/dev/dev_seed.dart`). Cada archivo se llama como el SKU del producto.

Son fotos de [Pexels](https://www.pexels.com), con la
[licencia de Pexels](https://www.pexels.com/license/): se pueden usar y modificar gratis, y la
atribución no es obligatoria, aunque igual la dejamos aquí. La licencia no permite vender las
fotos sin modificarlas, usarlas para insinuar que una persona o una marca respalda un producto,
ni redistribuirlas como un banco de fotos.

Están procesadas con `ProductImages.process`: hasta 800 px por lado, JPEG y sin metadatos.
